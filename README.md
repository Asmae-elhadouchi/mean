# Mean-Variance-Standard Deviation Calculator

A freeCodeCamp Scientific Computing with Python project.

## Requirements

- Python 3
- NumPy

## Install NumPy

```bash
python -m pip install -r requirements.txt
```

## Run

```bash
python main.py
```

The `calculate()` function accepts a list of exactly nine numbers and returns the mean, variance, standard deviation, maximum, minimum, and sum for columns, rows, and the flattened matrix.
